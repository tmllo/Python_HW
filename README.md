# Calculator

A simple command-line calculator written in Python. The project was created with `uv init`.

## Features

- Addition, subtraction, multiplication and division
- Asks again if you type an invalid number or menu option
- Does not allow division by zero
- Keeps running until you choose **Exit**

## Requirements

- [uv](https://docs.astral.sh/uv/)
- Python 3.14 (uv installs it automatically if needed)

## How to run

From the project folder:

```bash
uv run calculator.py
```

Or with plain Python:

```bash
python calculator.py
```

## Example

```
Simple Calculator
1. Add
2. Subtract
3. Multiply
4. Divide
5. Exit
Choose an operation (1-5): 4
Enter the first number: 10
Enter the second number: 4
Result: 2.5
```
